# SQL Data Analysis Project

## 📖 Project Overview
This project focuses on analyzing data using SQL to extract meaningful insights.
The objective is to practice SQL queries such as filtering, grouping, , and
aggregations on real-world like datasets.

## 🛠 Tools & Technologies
- MySQL
- SQL
- EXEL
## 📂 Dataset Details
- Dataset contains records related to products, orders, customers, and sales.
- Data is used only for learning and practice purposes.

## 🔍 Key Analysis Performed
- Data cleaning and filtering
- Category-wise analysis
- Price and quantity analysis
- Identifying trends and patterns
- Using CASE, GROUP BY, ORDER BY, JOIN
